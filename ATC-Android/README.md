# CLE ATC Simulator
A first playable Android ATC game prototype for Cleveland Hopkins (CLE). Includes an animated radar scope, selectable traffic, simulated aircraft movement, heading/altitude/speed commands, runway approach and takeoff/landing actions, three control positions, conflict alerts, event log, and Android speech synthesis for pilot acknowledgements.

## Build APK
Open the **Actions** tab and run **Build CLE ATC APK**. Download the `cle-atc-debug-apk` artifact from the completed workflow. This is an offline game prototype with simplified geometry and traffic logic; it is not certified ATC training software and must not be used for real-world operational decisions.
